# Vendored brand fonts (DSN-003)

Open Font License (OFL) families bundled for offline TV / Companion use.

| Family | Files | Weights |
|--------|-------|---------|
| Bricolage Grotesque | `BricolageGrotesque-Bold.ttf`, `BricolageGrotesque-ExtraBold.ttf` | 700, 800 |
| Figtree | `Figtree-Regular.ttf`, `Figtree-SemiBold.ttf` | 400, 600 |
| JetBrains Mono | `JetBrainsMono-Medium.ttf` | 500 |

Sources: upstream OFL releases (Google Fonts / JetBrains). See `OFL-*.txt` in this folder.

Do **not** add the `google_fonts` package — fonts are vendored and registered in `pubspec.yaml`.
